这个博客的开篇，本来想起一个更酷的标题。想了十分钟，决定还是老实一点。

## 第三次搬家

我写过三个博客。第一个在某技术社区，第二个在另一个技术社区，第三个我甚至不记得密码了。

共同点是：**每次搬家，文章都搬不干净**。图片挂了，代码块里的缩进乱了，评论区只剩下一句"该评论已删除"。最要命的是，你没法让旧链接跳转到新地址——那些年积累的搜索结果，一夜之间全变成 404。

所以这次我做了一个不同的决定：文章不再"放在某个平台上"，而是放在一个 Git 仓库里。

## 现在的工作方式

写作流程变成了这样：

1. 在 `src/content/blog/` 下面新建一个 `.md` 文件
2. 写正文，用 front-matter 填标题、日期、标签
3. `git push`
4. GitHub Actions 自动构建，发布到 `*.github.io`，几十秒后上线

没有任何后台、数据库、插件、升级提醒。文章是纯文本，编辑器随便挑，历史记录 Git 全帮我记着。

> 内容的所有权，取决于它能不能在你不想干了的时候被完整带走。Markdown 文件可以。

## 会写什么

主要是三类：

- **技术笔记**：踩过的坑、读过的源码、想明白的原理
- **工具与方法**：怎么让日常的重复劳动少一点
- **随笔**：读书、生活，以及一些暂时没有答案的问题

不追求日更，也不追热点。写清楚一件事，比写十篇水文更难，也更有意思。

如果你也想给自己留一块不被打扰的地方，欢迎从 [为什么是静态博客](/blog/why-static-blog/) 开始看。
